# 0.1.0

## Added

- Apartado de certificaciones completo (T-001, verificado el 2026-10-18):
  - Nuevo editor `src/lib/components/editors/CertificationsEditor.svelte` con los
    campos `name`, `organization`, `issueDate`, `expiryDate` (opcional),
    `credentialId`, `url` e `image` (preview con elegir/quitar), siguiendo el
    patrón de `LanguagesEditor.svelte`.
  - Nueva pestaña `certifications` en `src/lib/components/Editor.svelte`, entre
    `languages` y `version`.
  - Sello de la certificación en el render: `ResolvedCertification.image` en
    `src/lib/core/resolver.ts` y `<img class="cv-cert-badge">` en la rama
    `certification` de `src/lib/templates/components/CvItem.svelte`, con estilos
    `.cv-entry--cert` y `.cv-cert-badge` en `src/lib/templates/{modern,sidebar,elena-pdf}.css`.
  - Claves i18n nuevas en `src/lib/i18n/{es,en}.json`: `fields.issueDate`,
    `fields.expiryDate`, `fields.credentialId`, `fields.image`, `fields.imagePick`,
    `fields.imageRemove`.
  - Test "migra el campo `document` de certificaciones a `image`" en
    `src/lib/import/json.test.ts`.

## Changed

- El campo de imagen de `Certification` se renombra de `document` a `image`
  (`src/lib/domain/schema.ts`, `src/lib/domain/defaults.ts`). `createCertification()`
  devuelve `image: undefined`.
- `parseProfile()` (`src/lib/import/json.ts`) aplica `migrateLegacyFields()`: si una
  certificación guardada trae `document` y no `image`, copia el valor a `image` y
  borra `document`. `SCHEMA_VERSION` no se incrementa (compatibilidad hacia atrás
  con workspaces ya guardados).
